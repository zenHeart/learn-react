## 修复中保留的反例

- JSX 测试误存为 `.ts` 且导入错误：改为 `.tsx`，配置 DOM 环境并实际运行。
- 口令出现在调试对象与弹窗：移除回显；用合成值验证可见文字不包含口令。
- 定时器返回加载文本冒充 Suspense：改为真实 lazy 模块导入。
- 根路由流式 fallback 在无 JS 时遮住后续标题：拆成完整 HTML 根页面与单独 `/slow` 流式实验。搜索响应字符串不能代替可见性验收。
- 原生 modal 在 Tab 序列中允许进入浏览器导航区域：测试检查背景应用控件不可获得焦点，关闭后回到触发按钮；不把浏览器 chrome 当页面控件。
