函数组件监听变化的 5 种核心方法

1. useEffect — 副作用监听

useEffect(() => { console.log('count 变化了', count); // 依赖数组中的变量变化时执行 }, [count]); // ← 依赖数组是关键 // 常见场景 useEffect(() => { // 无依赖 → 每次渲染后执行 document.title = `count: ${count}`; }); useEffect(() => { // [] 空依赖 → 仅首次挂载执行 const subscription = subscribe(handler); return () => subscription.unsubscribe(); // 清理函数 }, []);
✅ 最佳场景：副作用（API调用、订阅、手动 DOM 操作）

2. useLayoutEffect — 同步副作用

useLayoutEffect(() => { // DOM 更新后同步执行，浏览器不会绘制 // 直到 useLayoutEffect 执行完毕 domRef.current.scrollIntoView(); }, [依赖]);
⚠️ 与 useEffect 区别：时机不同，useLayoutEffect 阻塞渲染

3. useMemo — 计算结果缓存

const memoizedValue = useMemo(() => computeExpensiveValue(a, b), [a, b] // 依赖变化时重新计算 );
✅ 最佳场景：复杂计算结果缓存，避免每次渲染重复计算

4. useCallback — 回调函数稳定化

const memoizedCallback = useCallback( (param) => { doSomething(a, param); }, [a] // 依赖变化时返回新函数，否则返回旧函数 );
✅ 最佳场景：子组件依赖的回调函数，避免子组件不必要的重渲染

5. 自定义 Hook 订阅模式

// Mbox 风格：创建一个可复用的订阅型 Hook function useMboxStore(selector) { const [state, setState] = useState(selector(store.getState())); useEffect(() => { const unsubscribe = store.subscribe(() => { const newState = selector(store.getState()); setState(prev => { return newState === prev ? prev : newState; }); }); return unsubscribe; }, []); // 无限订阅，需要自行比较新旧值 return state; } // 使用 const userName = useMboxStore(state => state.user.name);
✅ 最佳场景：全局状态管理（Redux/Zustand），细粒度订阅避免不必要渲染
