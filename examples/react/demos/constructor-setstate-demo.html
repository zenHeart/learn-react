原理说明

  • 构造器执行时机：组件实例化时调用，此时 fiber 节点尚未创建
  • setState 的本质：将状态变更放入更新队列，等待 fiber 消费
  • 为什么被忽略：没有 fiber 节点，setState 的更新无处可去，直接丢弃
  • React 15 vs 16+：React 15 警告「不能在 state transition 中调用 setState」，React 16+ 警告「组件未挂载时调用了 setState」
// ❌ 错误 — setState 在构造器中被静默忽略 constructor(props) { super(props) this.state = { count: 0 } this.setState({ count: 10 }) // 不生效 } // ✅ 正确 — 直接赋值初始状态 constructor(props) { super(props) this.state = { count: 10 } // 直接设为 10 } // ✅ 正确 — 基于 props 计算初始状态 constructor(props) { super(props) this.state = { fullName: `${props.firstName} ${props.lastName}` } }
