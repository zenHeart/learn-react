🎯 React Navigation: header vs headerTitle 区别演示

📚 核心概念
在 React Navigation 中配置导航栏时，header 和 headerTitle 是两个不同的属性，有着完全不同的用途：
属性 类型 用途 灵活度
headerTitle string 设置导航栏的标题文本 低 — 只能显示文本
header React Component 完全自定义导航栏 高 — 可以任意布局
🔤 headerTitle 示例 — 字符串标题
headerTitle 接收一个简单的字符串，直接渲染为导航栏标题。这是 React Navigation 默认的方式。
const Stack = createNativeStackNavigator(); function HomeScreen() { return ( <Stack.Navigator> <Stack.Screen name="Home" component={HomeScreen} options={{ headerTitle: "首页", // ✅ 字符串 headerStyle: { backgroundColor: '#4A90E2' }, headerTintColor: '#FFF', }} /> </Stack.Navigator> ); }

🎨 header 示例 — 自定义组件
header 接收一个 React 组件，允许你完全自定义导航栏的样式和内容。可以添加按钮、搜索框、Logo 等任何元素。
function CustomHeader({ title, onShare, onFavorite }) { return ( <View style={styles.header}> <Text style={styles.title}>{title}</Text> <View style={styles.actions}> <TouchableOpacity onPress={onShare}> <Text>分享</Text> </TouchableOpacity> <TouchableOpacity onPress={onFavorite}> <Text>收藏</Text> </TouchableOpacity> </View> </View> ); } function ArticleScreen() { return ( <Stack.Navigator> <Stack.Screen name="Article" component={ArticleScreen} options={{ header: (props) => ( <CustomHeader title="文章详情" onShare={() => console.log('分享')} onFavorite={() => console.log('收藏')} {...props} /> ), }} /> </Stack.Navigator> ); }

⚠️ 重要区别

当选择 headerTitle 模式时，只能修改标题文字和基础样式。
当选择 header 模式时，可以完全自定义导航栏的每一个细节！

⚖️ headerTitle vs header 对比
特性 headerTitle (字符串) header (组件)
数据类型 string React.Element / Function
自定义样式 ✅ 通过 headerStyle ✅ 完全自由
添加按钮/图标 ❌ 不能 ✅ 完全支持
响应点击事件 ❌ 不能 ✅ 可以
接收 Navigation props ❌ 不接收 ✅ 接收
渲染性能 ⚡ 更快（轻量） 📦 略重（完整组件）
适用场景 简单标题 复杂导航栏
💡 最佳实践建议

✅ 推荐：按需选择

  • 只需要显示标题 → 使用 headerTitle
  • 需要自定义样式 → 使用 headerTitle + headerStyle
  • 需要按钮/图标/搜索框 → 使用 header 自定义组件
  • 需要访问 navigation/route → 使用 header 函数形式

❌ 避免：常见错误

  • 不要将组件传给 headerTitle（只接受字符串）
  • 不要忘记在 header 组件中传递 props
  • 不要同时混用两者导致冲突
