2. 闭包陷阱 / Closure Trap

setInterval 中的状态更新 / State Update in setInterval

演示在 setInterval 回调中使用直接状态值导致的闭包陷阱。

0
Interval Speed:
闭包陷阱! 计数器停在了某个值，因为 setInterval 闭包捕获了初始状态。

Closure Trap! Counter stopped at a value because setInterval closure captured the initial state. 
// 陷阱代码 / Trap Code:
useEffect(() => {
  setInterval(() => {
    setCount(count + 1); // count 是闭包中的旧值!
                           // count is old value in closure!
  }, 1000);
}, []);

// 正确做法 / Correct:
setInterval(() => {
  setCount(prev => prev + 1); // 使用函数式更新
                               // Use functional update
}, 1000);
